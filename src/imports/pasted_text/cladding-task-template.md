# ADDITION — CLADDING DYNAMIC SCHEDULING TASK TEMPLATE

## Cladding Project Size Selection

When a project is assigned to the **Cladding / Metal Panel team**, there needs to be a separate **Cladding Project Size** selection.

Required selections:

* **Large**
* **Medium**
* **Small**

This selection applies **only to the Cladding scope** and must remain completely independent from the Glass project size, Glass tasks, Glass assignment, and Glass schedule.

Selecting the Cladding project size should automatically generate the applicable Cladding estimating task list and default hours below.

### Default Total Cladding Hours

| Project Size | Total Default Hours |
| ------------ | ------------------: |
| **Large**    |        **30.5 hrs** |
| **Medium**   |          **18 hrs** |
| **Small**    |          **11 hrs** |

These hours should automatically enter the assigned Cladding estimator's dynamic schedule.

The hours should remain editable at the individual task level when a specific project requires more or less time.

# 4. Plan Set Review & Takeoff

### Default Hours

* **Large:** 16 hrs
* **Medium:** 8 hrs
* **Small:** 4 hrs

This is the primary Cladding takeoff and drawing-review task.

### A. Design Criteria

Review:

* General Notes
* Building Code
* Design Loads
* Wind Pressures
* Performance Requirements
* Fire Ratings
* Accessibility Requirements

### B. Architectural Drawing Takeoff

Review and perform takeoff from:

* Overall Floor Plans
* Enlarged Floor Plans
* Overall Elevations
* Enlarged Elevations
* Reflected Ceiling Plans
* Roof Plans
* Exterior Details

### C. Quantities

Capture applicable quantities for:

* ACM
* PSS
* IMP
* Louvers
* Louvered Roof Screens
* Extruded Aluminum Planks
* Extruded Aluminum Battens
* FC
* HPL
* Metal Specialties
* Flashings

### D. Review Other Drawing Disciplines

Review applicable:

* Structural Drawings
* Waterproofing Details
* Interior Details

### E. Identify Drawing Conflicts

Review for conflicts between:

* Drawings and Specifications
* Floor Plans and Elevations
* Elevations and Details
* Schedules and Details
* Architectural and Structural Drawings
* Architectural and Mechanical Drawings

### F. Missing Information

When information is missing:

* Request clarification from the General Contractor
* Submit an RFI when necessary

# 5. Build Costing Sheet

### Default Hours

* **Large:** 6 hrs
* **Medium:** 4 hrs
* **Small:** 2 hrs

### A. Costing Sheet

Complete:

* Enter all piece cut lists
* Enter all final material pricing
* Enter all labor hours
* Enter equipment costs
* Enter subcontractor costs
* Verify taxes are applied correctly
* Review final markups
* Confirm final selling price before proposal submission

### B. Bond Calculator

Complete applicable bond calculations.

### C. Job Recap

Verify:

* Labor calculations
* Selected vendor totals
* Applicable glazing totals
* Overall material costs
* Labor hours generated from production rates

### D. Equipment

Enter anticipated equipment requirements including:

* Boom Lifts
* Scissor Lifts
* Forklifts
* Cranes
* Specialized Installation Equipment

### E. Swing Stage

Account for:

* Rental Duration
* Mobilization
* Installation
* Removal
* Safety Requirements

### F. Vendor Quote Management

For each applicable vendor quotation:

* Review specification compliance
* Review square-foot comparisons
* Compare pricing from multiple qualified vendors whenever possible
* Confirm the quote satisfies the project's design criteria

### G. Material Lead Times

Request material lead times from every supplier when they are not included with the original quotation.

Document lead times to:

* Identify schedule risks
* Assist Business Development
* Support schedule qualifications
* Coordinate procurement planning

# AUTOMATIC SCHEDULING BEHAVIOR

When the Cladding scope is assigned:

**Assign Cladding Estimator**
→ **Select Cladding Project Size**
→ **Generate Cladding Task Template**
→ **Apply Size-Based Default Hours**
→ **Dynamic Scheduler Places Tasks**
→ **My Week Updates**
→ **My Calendar Updates**
→ **My Capacity Updates**
→ **Team Capacity Updates**

The estimator should not have to manually create these standard tasks for every project.

---

# TASK SEQUENCING

The dynamic scheduler should generally maintain the logical Cladding workflow:

**1. Project Acceptance & Customer Engagement**
↓
**2. Download & Review Project Documents**
↓
**3. Vendor Distribution**
↓
**4. Plan Set Review & Takeoff**
↓
**5. Build Costing Sheet**
↓
**6. Write Proposal**
↓
**7. Create Presentation Packet**
↓
**8. Submit Proposal to Customer**
↓
**9. Customer Follow-Up**

Dynamic scheduling can determine the specific working days based on capacity and bid date, but it should maintain task dependencies where one task logically needs to occur before another.

Vendor Distribution may occur as soon as the initial document review provides enough information to issue RFQs and should not unnecessarily wait for the entire takeoff to be completed.

---

# BID DATE PRIORITY

The existing dynamic scheduling rule remains in effect.

Cladding tasks should be scheduled based on:

* Bid Date
* Remaining Working Days
* Task Sequence
* Required Task Hours
* Current Estimator Capacity
* Existing Higher-Priority Projects
* Completed Tasks
* Project Reassignment
* Project Closeout

As bid dates approach, the scheduler should dynamically reorganize the estimator's remaining workload while preserving necessary task dependencies.

---

# CLADDING / GLASS SEPARATION — CRITICAL RULE

These Cladding templates must **never automatically generate Glass tasks**.

Likewise, a Glass project-size selection must not create or alter these Cladding tasks.

The architecture remains:

**Project**
→ **Glass Scope**
→ Glass Assignee
→ Glass Size
→ Glass Tasks
→ Glass Schedule

and independently:

**Project**
→ **Cladding Scope**
→ Cladding Assignee
→ Cladding Size
→ Cladding Tasks
→ Cladding Schedule

Both scopes may exist under the same project, but their task ownership, hours, scheduling, and capacity calculations must remain separate.

---

# REASSIGNMENT

If the Cladding scope is reassigned:

* Existing Cladding tasks transfer to the new Cladding estimator.
* Completed Cladding tasks remain completed.
* Remaining hours transfer with the active tasks.
* Future scheduled Cladding work leaves the previous estimator.
* The new estimator's schedule is dynamically recalculated.
* Glass assignments and Glass scheduling remain unaffected.

---

# CLADDING CLOSEOUT

If the Cladding scope is closed out:

* Remaining active Cladding tasks immediately leave the schedule.
* Remaining Cladding hours are removed from capacity.
* Cladding tasks leave My Week and My Calendar.
* Team Capacity updates.
* Historical/completed Cladding task records remain available.

Closing the Cladding scope must **not close the Glass scope**.

---

# MANUAL TASK ADJUSTMENT

The size templates provide the default scheduling baseline, but individual project conditions may require adjustments.

Authorized users should be able to change the estimated hours for an individual Cladding task.

Example:

A Medium project normally generates:

**Plan Set Review & Takeoff — 8 hrs**

If the project is unusually complicated, the estimator or manager could change it to:

**Plan Set Review & Takeoff — 12 hrs**

Dynamic scheduling and capacity should immediately recalculate using the revised 12-hour value.

The underlying project size should remain **Medium** unless the user intentionally changes the overall project-size classification.
